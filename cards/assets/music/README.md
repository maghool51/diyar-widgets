# assets/music/

موسیقی پس‌زمینه‌ی کارت‌ها با `js/core/music.js` مدیریت می‌شود و از
همین حالا از دو نوع منبع پشتیبانی می‌کند — بدون نیاز به تغییر کد:

## حالت ۱: تولیدشده (پیش‌فرض فعلی `birthday-shad`)

```json
"music": "generated"
```

یک ملودی پنتاتونیک ملایم با Web Audio API ساخته می‌شود — بدون فایل
خارجی، بدون مسئله‌ی کپی‌رایت. برای وقتی مناسب است که هنوز فایل
موسیقی مجاز/دلخواه ندارید.

## حالت ۲: فایل صوتی واقعی (وقتی فایل موسیقی آماده کردید)

1. فایل MP3 خود را همین‌جا قرار دهید، مثلاً: `assets/music/birthday.mp3`
   (یا هر URL عمومی دیگری که گیرنده‌ی لینک هم بتواند به آن دسترسی داشته باشد).
2. در `data/templates.json`، فیلد `"music"` همان Template را به
   مسیر فایل تغییر دهید:

```json
"music": "assets/music/birthday.mp3"
```

همین کافی است — `music.js` به‌طور خودکار به‌جای Web Audio، از یک
`<audio loop>` با Fade-in استفاده می‌کند. اگر فایل پیدا نشود یا پخش
با خطا مواجه شود، دکمه بی‌صدا غیرفعال می‌شود و کارت بدون موسیقی کامل
کار می‌کند — هیچ خطای Console و هیچ صفحه‌ی خراب‌شده‌ای رخ نمی‌دهد.

## آماده برای انتخاب موسیقی در Builder (گام بعدی، هنوز پیاده نشده)

معماری فعلی (`music: "generated" | "<مسیر فایل>"`) از همین حالا برای
افزودن یک گزینه‌ی «🎵 موسیقی کارت» در فرم Builder (بدون موسیقی /
پیش‌فرض مناسبت / فایل دلخواه) آماده است؛ فقط کافی است یک `<select>`
جدید در فرم اضافه شود که مقدار `state.music` را قبل از رندر پیش‌نمایش
override کند. فعلاً Upload واقعی فایل توسط کاربر پیاده‌سازی نشده، چون
طبق ماهیت GitHub Pages (بدون سرور)، فایل باید در یک مکان عمومیِ
اینترنتی (مثل همین مخزن یا یک CDN) قرار بگیرد تا گیرنده‌ی لینک هم آن
را بشنود.
