# مسیریابی و لینک سرویس‌ها (routes)

هر ۶ سرویس (گوگل‌مپ، مسیریابی گوگل، ویز، نشان، بلد، اپل‌مپ) پشتیبانی می‌شوند. برای هرکدام
غیر از بلد، اگر لینک اختصاصی در `config.js → routes` ندهید، لینک به‌طور خودکار و
با فرمت رسمی همان سرویس از روی `coordinates` ساخته می‌شود. اگر بخواهید لینک
دستی بدهید (مثلاً یک لینک short/embed اختصاصی)، کافی است در `routes` مقدار
همان کلید را پر کنید:

```javascript
routes: {
  google: "",
  navigation: "",
  apple: "",
  waze: "",
  neshan: "",
  balad: ""
}
```

### درباره‌ی خطای «مکان اشتباه یا 404» در نشان و بلد

- **نشان:** لینک قبلی (`neshan.org/maps?...`) رسمی نبود و همین باعث خطا
  می‌شد. فرمت درست و مستند طبق `platform.neshan.org/api/`، `https://nshn.ir/?lat=..&lng=..`
  است که الان به‌صورت پیش‌فرض استفاده می‌شود — نیازی به تنظیم دستی نیست.
- **بلد:** بلد هیچ فرمت رسمی و مستندی برای ساخت لینک از روی مختصات ندارد؛
  اشتراک‌گذاری در اپ بلد یک لینک با توکن کوتاه تصادفی تولید می‌کند که از قبل
  قابل پیش‌بینی نیست. به همین دلیل ویجت هرگز لینک حدسی برای بلد نمی‌سازد —
  اگر `routes.balad` خالی باشد، **دکمه‌ی بلد اصلاً نمایش داده نمی‌شود** (به‌جای
  نمایش یک دکمه‌ی خراب). برای فعال‌کردنش:
  1. مکان را در اپ بلد پیدا کنید.
  2. دکمه‌ی اشتراک‌گذاری را بزنید و لینک را کپی کنید.
  3. همان لینک را در `config.js → routes.balad` قرار دهید.

# انتخاب موتور نقشه (map.provider)

از این نسخه به بعد می‌توانید موتور نمایش نقشه را در `config.js` انتخاب کنید:

```javascript
map: {
  provider: "google",      // "google" یا "leaflet"
  googleEmbedUrl: "",      // اختیاری — لینک دقیق از «اشتراک‌گذاری → جاسازی نقشه» گوگل‌مپ
  fallback: "leaflet"      // اگر Google Maps در دسترس نبود، به این موتور برگرد
}
```

- **`provider: "google"`** — نقشه با Google Maps Embed نمایش داده می‌شود. برای
  مکان‌هایی مثل امامزاده سید محمد ساغند که در گوگل‌مپ ثبت شده‌اند، این گزینه
  دقیق‌تر است.
  - اگر `googleEmbedUrl` را خالی بگذارید، لینک به‌طور خودکار و **بدون هیچ
    API Key‌ای** از روی `coordinates` ساخته می‌شود.
  - اگر می‌خواهید دقیقاً همان POI ثبت‌شده در گوگل‌مپ (با اسم، عکس و نظرات
    واقعی‌اش) نمایش داده شود: در گوگل‌مپ مکان را پیدا کنید → دکمه‌ی
    اشتراک‌گذاری → «جاسازی نقشه» (Embed a map) → کد iframe را کپی کنید → فقط
    مقدار `src="..."` را در `googleEmbedUrl` بگذارید. این روش هم رایگان و
    بدون API Key است (با روش پولی «Google Maps Embed API» که نیاز به کلید
    و صورت‌حساب Cloud دارد اشتباه نشود).
- **`provider: "leaflet"`** یا نبود کامل بخش `map` در `config.js` — دقیقاً
  همان رفتار نسخه‌ی قبلی (OpenStreetMap/Leaflet).
- **زنجیره‌ی fallback:** اگر Google Maps بارگذاری نشود (تایم‌اوت ۶ ثانیه‌ای،
  خطای شبکه یا فیلترینگ)، به‌طور خودکار به موتور مشخص‌شده در `fallback`
  سوییچ می‌شود. اگر آن هم شکست بخورد (یا `fallback` تنظیم نشده باشد)، فقط
  پیام «نقشه در دسترس نیست» به همراه دکمه‌های مسیریابی نمایش داده می‌شود —
  ویجت هیچ‌وقت کرش نمی‌کند.

# تنظیم مکان جدید

برای استفاده از ویجت برای مکان دیگر فقط فایل زیر را تغییر دهید:

```
config.js
```

نیازی به تغییر فایل‌های:

```
widget.js
widget.css
index.html
```

نیست.

موارد قابل تغییر:

- نام مکان
- مختصات جغرافیایی
- آدرس
- تصویر (باید یک لینک مستقیم به فایل عکس باشد، نه لینک یک صفحه‌ی وب)
- توضیح
- رنگ اصلی
- فعال یا غیرفعال کردن امکانات
- لینک‌های اختصاصی مسیریابی (`routes`)
- انتخاب موتور نقشه (`map`)

نمونه:

```javascript
placeName: "امامزاده سید محمد ساغند",

coordinates: {
    lat: 34.452167,
    lng: 57.272083
},

address:
"روستای ساغند، بین نایگ و هنویه، شهرستان بشرویه، استان خراسان جنوبی"
```

# استفاده در Blogfa

برای استفاده در وبلاگ:

1. فایل زیر را باز کنید:

```
blogfa.html
```

2. کد داخل آن را کپی کنید.

3. کد را در قالب یا پست وبلاگ قرار دهید.

ویجت بدون نیاز به نصب نرم‌افزار و بدون سرور اختصاصی اجرا می‌شود.

---

# انتشار با GitHub Pages

برای فعال‌سازی GitHub Pages:

1. وارد مخزن GitHub شوید.

2. مسیر زیر را باز کنید:

```
Settings
→ Pages
```

3. گزینه:

```
Deploy from a branch
```

را انتخاب کنید.

4. تنظیمات:

```
Branch: main
Folder: /root
```

را قرار دهید.

پس از فعال شدن، آدرس ویجت:

```
https://USERNAME.github.io/REPOSITORY/location/
```

خواهد بود.

# ترتیب بارگذاری فایل‌ها

برای اجرای صحیح در Blogfa:

ابتدا فایل تنظیمات:

```html
<script src="config.js"></script>
```

سپس:

```html
<script src="widget.js"></script>
```

بارگذاری شود.

فایل CSS نیز باید قبل از نمایش ویجت اضافه شود:

```html
<link rel="stylesheet" href="widget.css">
```

# خطایابی

اگر پیام:

```
نقشه در دسترس نیست
```

نمایش داده شد:

1. اتصال اینترنت را بررسی کنید.

2. مطمئن شوید Leaflet از CDN بارگذاری شده است.

3. فایل‌های زیر را بررسی کنید:

```
config.js
widget.js
widget.css
```

4. در مرورگر:

```
F12 → Console
```

را باز کنید و خطاها را بررسی نمایید.

حتی در صورت مشکل نقشه، دکمه‌های مسیریابی باید قابل استفاده باشند.

# حریم خصوصی موقعیت کاربر

- موقعیت کاربر (چه برای «فاصله تا مقصد» و چه برای «اشتراک‌گذاری موقعیت من»)
  هیچ‌وقت ذخیره نمی‌شود و به هیچ سروری ارسال نمی‌شود.
- ویجت از Cookie استفاده نمی‌کند.
- دسترسی به موقعیت فقط با اجازه‌ی لحظه‌ای مرورگر (`navigator.geolocation`) و
  فقط در همان لحظه‌ی کلیک کاربر خوانده می‌شود.
