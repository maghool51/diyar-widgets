# diyar-widgets

مجموعه‌ای از ویجت‌های مستقل، بدون Backend و آماده‌ی GitHub Pages. هر
پوشه یک ماژول کاملاً جدا و مستقل است (README و مستندات خودش را دارد):

- [`hadith/`](hadith) — ویجت حدیث روز
- [`cards/`](cards) — 🌸 کارت‌پستال دیجیتال دیار قدمگاه (ساخت و
  اشتراک‌گذاری کارت‌پستال برای مناسبت‌های مذهبی و غیرمذهبی)
- [`player/`](player) — پلیر مالتی‌مدیای دیار
- [`location/`](location) — ویجت موقعیت مکانی
- [`news/`](news), [`diyar-news/`](diyar-news) — تیکر و صفحه‌ی اخبار
- [`visitor/`](visitor) — ویجت آمار بازدید
- [`gallery/`](gallery) — گالری تصاویر
- [`Paint-pro/`](Paint-pro) — ابزار نقاشی حرفه‌ای
