# Diyar Map Widget

ویجت نقشه، مسیریابی و اشتراک‌گذاری موقعیت — سبک، بدون وابستگی به Framework،
و ۱۰۰٪ سازگار با **Blogfa** و هر پلتفرم وبلاگ‌نویسی استاتیک دیگر.

فقط **HTML + CSS + JavaScript خالص**. بدون jQuery، بدون React/Vue/Angular،
بدون Node.js، بدون Build Tool، بدون ماژول ES، بدون Service Worker و بدون
Cookie. همه‌چیز به‌صورت فایل استاتیک اجرا می‌شود و می‌تواند روی
**GitHub Pages** میزبانی شود.


## ۲) ویژگی‌ها

- نمایش نام، تصویر، آدرس و توضیح مکان
- نقشه‌ی کوچک مبتنی بر **OpenStreetMap / Leaflet** با **Lazy Loading**
  (نقشه فقط زمانی بارگذاری می‌شود که ویجت وارد دید کاربر شود)
- در صورت شکست بارگذاری نقشه (اینترنت ضعیف، فیلترینگ و…)، ویجت **بدون خطا**
  و فقط با دکمه‌های مسیریابی نمایش داده می‌شود
- ۶ دکمه‌ی مسیریابی با آیکون اختصاصی: گوگل‌مپ، مسیریابی گوگل، ویز، نشان،
  بلد، اپل‌مپ (هرکدام قابل غیرفعال‌سازی)
- اشتراک‌گذاری با **Web Share API** و در صورت عدم پشتیبانی مرورگر،
  بازگشت خودکار به کپی لینک
- کپی مختصات و کپی لینک گوگل‌مپ با یک کلیک
- **QR Code تولیدشده به‌صورت کاملاً محلی** (بدون فراخوانی هیچ سرویس آنلاین)
- نمایش فاصله‌ی کاربر تا مقصد و جهت تقریبی (فقط با اجازه‌ی صریح کاربر
  از طریق Geolocation API؛ در غیر این‌صورت این بخش نمایش داده نمی‌شود)
- Toast Message برای بازخورد بصری
- طراحی **Material 3**، کاملاً **Responsive** و **RTL**
- فونت **Vazirmatn**
- **Dark Mode** خودکار یا دستی
- دسترس‌پذیری کامل: نقش‌های ARIA، `aria-live`، برچسب‌های گویا و
  ناوبری کامل با صفحه‌کلید (Tab / Enter / Focus قابل مشاهده)
- مدیریت کامل خطا در تمام مراحل (بارگذاری تصویر، نقشه، Geolocation، Clipboard)

## ۳) شخصی‌سازی — فقط `config.js`

تمام اطلاعات ویجت از یک فایل خوانده می‌شود: `config.js`. کافی است مقادیر
زیر را با اطلاعات مکان خودتان جایگزین کنید:

```js
window.DiyarMapConfig = {
  containerId: "diyar-map-widget",
  placeName: "کافه دیار",
  coordinates: { lat: 35.715298, lng: 51.404343 },
  address: "تهران، خیابان ولیعصر...",
  image: "https://...",
  description: "توضیح کوتاه درباره مکان",
  primaryColor: "#6750A4",
  mapZoom: 16,
  buttons: {
    googleMaps: true,
    googleNavigation: true,
    waze: true,
    neshan: true,
    balad: true,
    appleMaps: true
  },
  features: {
    showMap: true,
    showShare: true,
    showQRCode: true,
    showDistance: true,
    showDirection: true,
    lazyLoad: true,
    darkMode: "auto"   // "auto" | "light" | "dark"
  }
};
```

هیچ‌کدام از فایل‌های `widget.js` یا `widget.css` نیازی به ویرایش ندارند.

## ۴) استقرار روی GitHub Pages (گام‌به‌گام)

1. یک مخزن (Repository) جدید در گیت‌هاب بسازید، مثلاً به نام
   `diyar-map-widget`.
2. تمام فایل‌های این پروژه (`widget.css`، `widget.js`، `config.js` و در
   صورت تمایل بقیه‌ی فایل‌ها) را در ریشه‌ی همان مخزن آپلود کنید.
3. به مسیر **Settings → Pages** در مخزن بروید.
4. در بخش **Source**، گزینه‌ی «Deploy from a branch» را انتخاب کرده و
   شاخه‌ی `main` و پوشه‌ی `/root` را انتخاب کنید، سپس **Save** بزنید.
5. پس از چند دقیقه، گیت‌هاب آدرسی شبیه زیر در اختیار شما قرار می‌دهد:

   ```
   https://YOUR-USERNAME.github.io/diyar-map-widget/
   ```

6. فایل‌های CSS و JS شما اکنون از این آدرس‌ها در دسترس‌اند:

   ```
   https://YOUR-USERNAME.github.io/diyar-map-widget/widget.css
   https://YOUR-USERNAME.github.io/diyar-map-widget/config.js
   https://YOUR-USERNAME.github.io/diyar-map-widget/widget.js
   ```

از این پس، هر بار که `config.js` یا `widget.js` را در گیت‌هاب به‌روزرسانی
کنید، وبلاگ شما به‌صورت خودکار **آخرین نسخه‌ی ویجت** را نمایش می‌دهد؛ چون
Blogfa فقط به این آدرس‌ها لینک می‌دهد و محتوای فایل را مستقیماً از
گیت‌هاب می‌خواند.

## ۵) استفاده در Blogfa

کافی است محتوای فایل `blogfa.html` را کپی کرده و در محلی از **پست** یا
**قالب** وبلاگ خود (هرجا که HTML خام قابل درج است) جای‌گذاری کنید:

```html
<div id="diyar-map-widget"></div>
<link rel="stylesheet" href="https://YOUR-USERNAME.github.io/YOUR-REPO/widget.css">
<script src="https://YOUR-USERNAME.github.io/YOUR-REPO/config.js"></script>
<script src="https://YOUR-USERNAME.github.io/YOUR-REPO/widget.js"></script>
```

نکات مهم:

- `YOUR-USERNAME` و `YOUR-REPO` را با نام کاربری و نام مخزن گیت‌هاب خود
  جایگزین کنید.
- ترتیب بارگذاری فایل‌ها مهم است: `config.js` باید **پیش از** `widget.js`
  بارگذاری شود (همان‌طور که در نمونه بالا آمده).
- اگر می‌خواهید ویجت را در چند پست مختلف با اطلاعات متفاوت نمایش دهید،
  می‌توانید به‌جای لینک‌دادن به `config.js` مشترک، یک بلوک
  `<script>window.DiyarMapConfig = {...}</script>` مستقل و اختصاصی برای
  همان پست بنویسید (پیش از بارگذاری `widget.js`).
- برخی از پوسته‌های Blogfa ممکن است تگ `<script>` را درون متن پست فیلتر
  کنند؛ در این صورت کد را در بخش **HTML/JavaScript قالب** (نه ویرایشگر
  پست) قرار دهید که معمولاً بدون محدودیت است.

## ۶) نکات فنی

- ویجت هیچ Cookie‌ای ثبت نمی‌کند و هیچ داده‌ای را در سرور ذخیره نمی‌کند.
- نقشه از **Leaflet** (کتابخانه‌ی متن‌باز نمایش نقشه) و کاشی‌های
  **OpenStreetMap** استفاده می‌کند که هر دو از طریق CDN عمومی
  (`unpkg.com`) بارگذاری می‌شوند؛ این کتابخانه به‌صورت **Lazy** و تنها در
  صورت نیاز بارگذاری می‌شود و هیچ وابستگی build-time ندارد.
- در صورت عدم دسترسی به اینترنت برای بارگذاری Leaflet، ویجت به‌طور خودکار
  حالت جایگزین (فقط دکمه‌های مسیریابی) را نمایش می‌دهد و **هیچ خطایی در
  کنسول کاربر نهایی مانع کارکرد ویجت نمی‌شود**.
- QR Code به‌صورت کامل در مرورگر کاربر و بدون تماس با هیچ API خارجی
  تولید می‌شود (پیاده‌سازی محلی الگوریتم استاندارد QR).
- فاصله و جهت تنها در صورتی نمایش داده می‌شود که کاربر به‌صراحت دسترسی به
  موقعیت مکانی را تأیید کند؛ در غیر این‌صورت این بخش به‌سادگی پنهان
  می‌ماند و خطایی تولید نمی‌شود.
