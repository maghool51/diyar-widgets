# Diyar Map Widget

ویجت نقشه، مسیریابی و اشتراک‌گذاری موقعیت **دیار ویجت**؛
سبک، سریع، فارسی، راست‌چین و کاملاً سازگار با **Blogfa** و سایر پلتفرم‌های وبلاگ‌نویسی و سایت‌های استاتیک.

این ویجت برای معرفی و مکان‌یابی:

- 🕌 اماکن مذهبی
- 🏛️ اماکن تاریخی
- 🌿 جاذبه‌های گردشگری
- 🏪 فروشگاه‌ها و مکان‌های عمومی

طراحی شده است.
