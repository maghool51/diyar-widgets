# assets/music/

فعلاً موسیقی پس‌زمینه‌ی کارت «تولد شاد» با Web Audio API به‌صورت
برنامه‌ریزی‌شده (Procedural) تولید می‌شود — نه از یک فایل صوتی. دلیل:
هیچ فایل موسیقی با مجوز مشخص برای این پروژه در دسترس نبود، و پخش یک
فایل بدون مجوز روشن، ریسک کپی‌رایت دارد. به‌جایش `js/core/music.js`
یک ملودی پنتاتونیک ملایم و کوتاه می‌سازد — سبک، بدون فایل خارجی،
بدون هیچ محدودیت مجوز.

## اگر می‌خواهید یک فایل موسیقی واقعی (دارای مجوز/رایگان) اضافه کنید

1. فایل MP3 خود را همین‌جا قرار دهید، مثلاً: `assets/music/birthday-shad.mp3`
2. در `js/core/music.js`، تابع `createMusicToggle` را طوری تغییر دهید
   که وقتی `musicKey` یک مسیر فایل بود (نه `"generated"`)، به‌جای
   Web Audio، یک `<audio src="...">` بسازد و پخش/توقفش را به همان
   دکمه وصل کند.
3. در `data/templates.json`، فیلد `"music"` همان Template را به
   مسیر فایل تغییر دهید، مثلاً: `"music": "assets/music/birthday-shad.mp3"`.

هیچ تغییر دیگری لازم نیست — بقیه‌ی سیستم (دکمه، آیکون پخش/قطع،
مدیریت خطا) همان می‌ماند.
